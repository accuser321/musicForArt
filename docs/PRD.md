# PRD - Music For Art MVP

## 1. 目标

将音乐分析结果转换为有声书可执行后期方案，降低学生对音乐术语的理解门槛。

## 2. MVP 范围

- 创建项目
- 上传音频并生成时间锚点、风格标签、导演建议
- 输入文本并输出动作/情绪/音效建议
- 生成融合 cue sheet
- 导出完整 JSON 报告（API）

## 3. 用户流程

1. 创建项目
2. 上传音乐
3. 查看音乐报告
4. 粘贴章节文本
5. 查看文本报告
6. 生成融合执行单

## 4. 成功标准

- 用户可在 3 分钟内完成从上传到出报告
- 报告包含可直接进 DAW 的时间点建议
- 教师可据此布置分段作业
