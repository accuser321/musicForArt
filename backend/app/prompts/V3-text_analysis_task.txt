任务：基于 raw_text（可选结合 music_analysis_text/audio_context）输出“可映射到演绎时间轴”的文本证据。

输入：
- raw_text（必选）
- scenes（可选，系统预切分）
- music_analysis_text（可选，来自音乐分析）
- audio_context（可选，音乐结构化上下文）

输出目标（业务优先）：
1) 形成 scene_units（给执行单使用）；
2) 形成 clause_timeline（给演绎时间轴映射使用）；
3) 给出文本与音乐适配判断（供执行单汇总）。
4) 输出要“短、准、可执行”，优先保证 JSON 完整可解析。

关于 clause_timeline（重点增强）：
1) clause_timeline 不是普通分句列表，而是“核心时间证据”；优先保留最值得做旁白秒级对齐的语句。
2) 优先选择以下内容进入 clause_timeline：
   - 动作真正发生的句子
   - 情绪明显转折的句子
   - 场景切换或节奏切换的句子
   - 能触发音乐进入/退出的句子
   - 有明确音效提示价值的句子
3) 不要为了凑数量平均切分；弱信息句、重复说明句、纯铺垫句可不进 clause_timeline。
4) clause_timeline.text 必须尽量保留原文关键触发词，不要改写成总结句。
5) start_sec / end_sec 允许是“建议区间”，但要体现朗读节奏差异：
   - 长句、重情绪句、动作密集句可适当更长
   - 过渡句、短促指令句可适当更短
   - 禁止机械平均分配到每一句都差不多长
6) 若是对白或连续指令，优先保留真正推动节奏的句子，不必把所有对白都塞进 clause_timeline。
7) 若 scene_units 已经压缩，clause_timeline 仍应尽量保留“节奏拐点”证据，不要只剩平铺直叙句。

输出 JSON（必须完整，且只输出 JSON，不要任何前后解释）：
{
  "title": "文本分析报告",
  "text_theme": "文本主情绪与叙事方向",
  "fit_with_music": {
    "verdict": "适配/部分适配/不建议",
    "score": 0,
    "reasons": ["理由1","理由2","理由3"]
  },
  "scene_units": [
    {
      "scene_no": 1,
      "text_start_char": 0,
      "text_end_char": 52,
      "text_excerpt": "原文片段",
      "emotion": "主情绪",
      "emotion_change": "平稳/渐变/突变",
      "action_tags": ["动作标签"],
      "intensity": 65,
      "music_need": "无/弱/中/强",
      "entry_hint": "渐入/突入/不入",
      "exit_hint": "淡出/硬切/转场",
      "sfx_terms": ["音效词"]
    }
  ],
  "clause_timeline": [
    {

  "risks": ["风险"]

硬约束：
1) 只能输出一个 JSON 对象，禁止代码块标记、禁止额外说明文字。
2) 所有值使用中文。
3) scene_units 字符区间必须可供后续对齐。
4) clause_timeline 是后续时间证据核心；无法计算时返回 [] 并在 risks 解释原因。
4.1) clause_timeline 中每条 text 必须来自原文，不要自行概括改写。
4.2) clause_timeline 的字符区间必须准确落在 raw_text 上，不能漂移。
4.3) clause_timeline 若做压缩，优先保留“动作触发 / 情绪转折 / 转场 / 音效触发”这四类句子。
5) 禁止在 JSON 之外输出额外前后缀说明。
6) 若输出长度受限，优先保全 JSON 字段完整；字段值使用短句，不写长段落。
7) scene_units 必须覆盖输入中的主要场景，不得随意漏场景；若场景过多，优先保留高强度场景并在 risks 说明压缩策略。
8) title、text_theme、fit_with_music、scene_units、clause_timeline、emotion_curve、sfx_requirements、key_points、risks 均不得省略；若证据不足可返回空数组或保守对象，但字段必须存在。
9) title 字段固定写为“文本分析报告”，不得省略、不得改名、不得留空。

长度约束：
1) scene_units<=8，emotion_curve<=8，sfx_requirements<=10，clause_timeline<=12。
2) fit_with_music.reasons 固定 3 条，每条<=22字。
3) key_points<=4（每条<=22字），risks<=4（每条<=24字）。
4) title<=20字，text_theme<=50字，text_excerpt<=28字。
5) action_tags/sfx_terms 每项<=3个词，单词<=8字。
6) clause_timeline 中，优先保证“质量”而不是“数量”；宁可少而准，也不要满额但平庸。
