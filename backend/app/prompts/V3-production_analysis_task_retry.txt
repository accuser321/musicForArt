任务：这是执行单“重试兜底版”提示词。目标是保证可执行 JSON 完整输出。

输入：
- music_analysis
- text_analysis
- narration_timeline
- audio_markers/scenes/cues/fit

输出要求：
1) 必须先输出一个可解析 JSON；
2) JSON 后可追加 markdown（可选，简短）；
3) 禁止输出与字段无关的赘述。

JSON 字段（必须齐全）：
- title
- fit_verdict: {verdict, score, reasons[]}
- key_points: [string]
- sections: [{section_no,section_type,label,start_sec,end_sec,instruments[],new_instruments_vs_prev[],energy_level,layer_progression}]
- structure_logic: {pattern_guess,repeat_groups[],evidence[]}
- music_entry_plan: [{scene_no,text_start_char,text_end_char,text_excerpt,music_start_sec,music_end_sec,entry_reason,dialogue_music_ratio,sfx[]}]
- hit_points: [{time_sec,event,why}]
- risks: [string]
- export_hints: [string]
- markdown

硬约束：
1) 所有值使用中文。
2) 每个场景都要给 music_entry_plan；若信息不足也要给保守区间。
3) dialogue_music_ratio 必须是明确比例（如70/30）。
4) 若 narration_timeline 存在，优先使用其时间范围。

长度约束（严格）：
1) sections<=6，music_entry_plan<=8，hit_points<=6。
2) key_points<=5，risks<=5，export_hints<=5（单条<=26字）。
3) fit_verdict.reasons<=3（单条<=22字）。
4) markdown<=420字。
